## Method

- Stimulus: one pull-up instance per Monte Carlo sample (PU_EN = VPU = vsup), the trim code as the DC sweep variable (vcode 0 ... 15 at 1 step; TRIM<i> = bit i of the code, driven 0 / VPU by B sources; TRIM<i> = 1 shorts ladder segment i, code 0 = maximum resistance), the host 15 kohm from D+ to ground and a 1 mohm series resistor in the nominal campaign. All 16 codes therefore see the same mismatch draw, which is what trim-at-test selects from.
- Measurement per sample: V(DP) per code; R_eff = (VPU - V(DP)) / (V(DP)/15000) per code, as in sim/dplus-pullup-tolerance; `err_cNN_ohm` = |R_eff - 1500|; `best_err_ohm` = the minimum over the 16 codes; `n_in_window` = the number of codes with |R_eff - 1500| <= 75 ohm (inclusive 1.425-1.575 kohm).
- Graded per sample (each its own yield measurement, target_yield 0.99 at 95 % confidence): `best_err_ohm` <= 75 ohm and `n_in_window` >= 1, which are the same event stated twice (a sample passes when some code is inside the window); a sample with no passing code counts as a failing sample. A recorded run in which the yield claim is not supported (including a 'no passing code' outcome) is a FAIL record: the failure is the result, not a waived row.
- Selection limit: the code is chosen per sample (per die, as at test) and per corner; the record does not show that one calibration code survives voltage and temperature after trim at one condition.
- Each corner is its own population (one `klt sim` Monte Carlo request, backend batch, per corner); nothing is pooled across corners. `klt yield-samples` pairs each nominal campaign with its negative-control campaign (same deck, same seeds, 1 kohm in series), and `klt yield` grades the pair.
- Negative control (deterministic): 1 kohm in series with the output adds 1 kohm to every code, so no code can be inside the window and `n_in_window` is 0 on every sample; the yield report must flag both graded measurements `detected`.
- Mismatch activity: a non-zero sample stddev of `best_err_ohm` (yield report `distribution`) is the evidence that the draws reached the circuit; the ladder spread is the testbench model named above, the MOS spread is the PDK's.
- PDK: the pinned open_pdks revision of sim/pdk-pins.json (current pin); each record states the revision and the model library sha256.
- Corner `tt`: typical corner with mismatch enabled.
- Corner `binding`: binding corner of the 45-point record sim/dplus-pullup-tolerance/records/20261020-174332-ca4a45a.md: the largest best-code error (best_err_ohm 27.0493 ohm, best_r_ohm 1527.05) is at ff / 100 C / 3.30 V.
