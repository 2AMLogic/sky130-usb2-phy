## Method

- Stimulus: 16 pull-up instances (PU_EN = VPU), one per trim code 0..15, TRIM<i> = bit i of the code (TRIM<i> = 1 shorts ladder segment i, code 0 = maximum resistance), each with the host's 15 kohm from D+ to ground. Control inputs sit at 0 or VPU (the documented control domain, no thick-oxide gate sees more than VPU). VPU = the swept supply `vsup` (3.0 / 3.3 / 3.6 V).
- Raw measurement: V(DP) per code (`vdp_cNN_v`, DC operating point). Derived by sim/harness/trim.py and recomputed by the record lint from the raw envelope: I_load = V(DP)/15000 ohm [A, from D+ into the load, i.e. out of the pull-up]; R_eff = (VPU - V(DP))/I_load [ohm]. R_eff therefore includes the enable switch, the ladder and the bypass switches. A code with V(DP) not finite, not > 0 (zero current) or not < VPU yields no resistance and fails the corner.
- Acceptance (existential over codes, within each corner): at least one code with 1425 <= R_eff <= 1575 ohm, inclusive bounds, at each unique corner of the selected matrix (45 for the base experiment, 225 for the resistor-sets variant). The bound is NOT applied to every code. All 16 codes must be present and finite at every corner, even when another code passes. Best code = smallest |R_eff - 1500|, ties to the lowest code. Missing, duplicate or unexpected corners, a failed simulation, missing/non-finite code data or a corner with no passing code make the record FAIL.
- Per-corner derived data: `r_cNN_ohm` (all codes), `best_code`, `best_r_ohm`, `best_err_ohm`, `n_in_window`, `step_cNN_ohm` (R(code-1) - R(code), positive = resistance falls), `step_min_ohm`, `step_max_ohm`, `range_ohm` (R(code 0) - R(code 15)), `n_nonmonotonic` (adjacent pairs where resistance does not fall).
- Limit of the selection: the best code is chosen independently per corner. That proves the trim range and step cover every corner; it does not prove that a single calibration code is valid across voltage and temperature after trim at one condition.
- Disabled state (PU_EN = 0): `voff_d1_v` / `voff_d0_v` = V(DP) with TRIM=1111 / 0000 and the 15 kohm host load; `ioff_*_na` = current delivered into D+ by the pull-up (positive out of the pull-up) for d1 and d0 (through the load), dz (D+ forced to 0 V) and dh (D+ forced to VPU); `isup_*_na` = current drawn from VPU by each disabled instance. Only a sanity criterion is applied: D+ must stay at or below 0.8 V (the ratified single-ended VIL) with the 15 kohm load, i.e. not pulled up. No leakage limit is ratified, none is invented, and these records do not claim leakage compliance.
- `r_c00_ohm` spread >= 5 % across the grid is a harness-integrity bound (temperature and MOS corner sections took effect), not a spec row.
- Resistor coverage: each point's process section is one of 25 pinned-library sections = 5 MOS corners x {typical, ll, hh, hl, lh}; the section -> (MOS file, resistor set, capacitor set) mapping and the resolved library includes are recorded in evidence.json (`sections`) and checked by the lint against the approved map. The bare sections `ll`, `hh`, `hl`, `lh` carry the tt MOS corner.
- Compatibility: this record is a supplement to, not a replacement for, the 45-point records (res_typical only); those records are unchanged and keep their own frozen matrix.
