## Method

- Stimulus: the line input DM swept 0 V to 3.0 V, 1 mV step (3001 points), ideal source; supply = swept I/O rail vsup (3.0 / 3.3 / 3.6 V). 3.0 V is the lowest matrix supply, so the input never exceeds the rail.
- Output polarity: non-inverting, RXDM=1 (high) when DM is above the internal VREF threshold. Output decision level: RXDM crosses VDD/2 of the corner supply (node `half`).
- Switching threshold `vth_v`: the first rising crossing of RXDM through VDD/2 (`.meas dc ... WHEN v(rxdm)=v(half) RISE=1`), resolved by interpolation between 1 mV points. Ratified row VIH > 2.0 V, VIL < 0.8 V: read as 'an input at or above 2.0 V reads high and an input at or below 0.8 V reads low', so the crossing must lie strictly inside (0.8 V, 2.0 V); checked with exclusive bounds (`gt` 0.8 / `lt` 2.0), so an endpoint value fails. A missing or non-finite crossing fails the corner; an inverted receiver has no rising crossing and fails.
- Single crossing / monotonic: `vth_last_v` is the last crossing in either direction (`CROSS=LAST`); it must equal `vth_v` within one sweep step (1 mV, check `same_as`). A response that crosses more than once (non-monotonic, or rising then falling) fails.
- Valid levels beyond the window (correct polarity throughout, not a single crossing): `rxd_low_max_v` = maximum of RXDM over DM in [0, 0.8] V must be <= 0.1 x VDD; `rxd_high_min_v` = minimum of RXDM over DM in [2.0, 3.0] V must be >= 0.9 x VDD. `rxd_at_vil_v` / `rxd_at_vih_v` are the boundary probes at exactly 0.8 V and 2.0 V, checked with the same bounds.
- Output bounds (engineering criteria for the 3.3 V-domain RXDM, not USB driver VOH/VOL limits): high >= 0.9 x VDD and low <= 0.1 x VDD of the corner supply.
- `vref_v`: the internal divider reference (node `xrx.vref`) at input 0 V, checked as a fraction of the corner supply against a 0.35-0.50 sanity bound (design value about 0.425); not a spec row.
- `isup_ua`: receiver supply current (bias + divider) at input 1.4 V; sanity bound 1-500 uA, not a spec row.
- Resistor coverage: each point's process section is one of 25 pinned-library sections = 5 MOS corners x {typical, ll, hh, hl, lh}; the section -> (MOS file, resistor set, capacitor set) mapping and the resolved library includes are recorded in evidence.json (`sections`) and checked by the lint against the approved map. The bare sections `ll`, `hh`, `hl`, `lh` carry the tt MOS corner.
- Compatibility: this record is a supplement to, not a replacement for, the 45-point records (res_typical only); those records are unchanged and keep their own frozen matrix.
- Coverage: all 225 unique PVT/section points are judged with the unchanged exclusive (0.8 V, 2.0 V) crossing bounds, single-crossing, output-level, reference and current checks above.
